## 目录结构

- index.html —— 入口页，自动跳转到 guide.html
- guide.md —— 主文档，手机与公众号友好的 Markdown 版
- guide.html —— 与 Markdown 结构同步的桌面端样式页面，字体与图标全部内嵌，离线可用
- archive/guide-v1.md —— v1.0 长版（16 章）备份
- archive/guide-v1.html —— v1.0 长版 HTML 备份

## 本地查看

Markdown 直接用编辑器打开；HTML 双击即可，不依赖网络。
